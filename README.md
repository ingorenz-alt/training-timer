# Training Timer – Hantel-Workouts

Eine Single-Page-App für Hanteltraining mit animierten Piktogrammen und Timer.

## Programme

- **Morgenroutine A** – 5 Übungen, 2 Runden, ~10 Minuten
- **Morgenroutine B** – 5 Übungen, 2 Runden, ~10 Minuten  
- **Oberkörper** – 6 Übungen, 3 Runden, 20 Minuten
- **Unterkörper** – 5 Übungen, 4 Runden, 20 Minuten

## Features

- 🎯 Wählbare Anzahl Runden pro Programm
- 📱 Responsive Design (Desktop & Handy)
- 🔔 Ton- und Vibrationsfeedback (abschaltbar)
- 🖼️ Animierte Strichfigur-Piktogramme für jede Übung
- 🎨 Farbcodierung: Belastung (blau), Pause (grün), Vorbereitung (gelb)
- 📊 Fortschrittsbalken und Segmente-Übersicht
- 💾 Speichert Einstellungen lokal

## Verwendung

Öffne `training-a.html` im Browser oder deploye auf GitHub Pages / jede statische Hosting-Plattform.

Keine externe Dependencies – alles ist in einer Datei enthalten.

## Tasten

- **Start** – Trainng starten
- **Pause** – Trainning pausieren / fortsetzen
- **Zurück** – Vorherige Übung
- **Weiter** – Nächste Übung überspringen
- **Beenden** – Abbrechen

## Anmerkungen

- Wechsel/Pausen können je nach Programm unterschiedlich lang sein
- Hanteln sind in der App als „leicht" oder „schwer" gekennzeichnet
- Side Plank wird automatisch je 20 s auf jede Seite aufgeteilt
